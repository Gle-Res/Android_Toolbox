# 📱 安卓工具箱 (Android Toolbox)

🎉正式升级为安卓工具箱！

一款基于 **ADB + scrcpy** 的安卓设备管理工具，图形化界面。

支持设备信息查看、应用管理、文件传输、屏幕截图、无线投屏控制等功能，全中文界面，操作简单。

## ✨ 功能特性

**📱 设备管理**

- 设备信息一键读取（型号、系统、硬件、电池、运行状态等中文描述）
- 查看所有已连接设备（USB / 无线）
- 无线连接设备（IP:端口）
- 一键断开所有设备、重启 ADB 服务

**📦 应用管理**

- 安装 APK（支持覆盖安装、降级安装）
- 卸载应用（可选保留数据）
- 冻结 / 解冻应用
- 清除应用数据
- 查看应用列表（全部 / 第三方 / 系统）

**📁 文件传输**

- 推送文件到手机
- 从手机拉取文件到电脑
- 一键屏幕截图并保存到电脑

**🎮 无线投屏控制（scrcpy）**

- USB 直连 / 无线连接（自动切换 `tcpip 5555` 并连接）
- 自动获取设备 IP
- 支持限制分辨率、限制码率、关闭音频、保持常亮、无边框、全屏
- 支持录制 MP4 视频

**🛠️ 系统工具**

- ADB Shell 命令执行
- Logcat 日志查看（支持 TAG 过滤、崩溃日志、清空缓存）
- 重启设备（普通 / Recovery / Fastboot）
- 自定义 ADB 命令

## 🚀 快速开始

**系统要求**

- Windows 7 / 10 / 11（64 位）
- 一台开启了 **USB 调试** 的安卓设备

**下载使用**

1. 下载最新版压缩包
2. 解压到任意目录
3. 双击 `安卓工具箱.exe` 启动即可

**目录结构**

```
安卓工具箱/
├── 安卓工具箱.exe
├── platform-tools/
│   └── adb.exe
└── scrcpy/
    └── scrcpy.exe
```

程序会自动查找同目录下的 `adb.exe` 和 `scrcpy.exe`，没有则在系统 PATH 和常见路径中查找。

## 📖 使用说明

1. 手机开启 **开发者选项 → USB 调试**，用数据线连接电脑
2. 双击运行 `安卓工具箱.exe`
3. 右上角选择目标设备，点击「刷新」可重新扫描
4. 左侧菜单选择功能，点击按钮执行
5. 执行结果会显示在页面下方的日志框中

**无线投屏**

1. 先用 USB 连接设备一次
2. 进入「无线投屏控制」页面
3. 连接模式选择「无线（自动 tcpip 5555 + 连接）」
4. 点击「启动投屏」

## ⚙️ 技术栈

- **ADB** — 安卓调试桥
- **scrcpy** — 开源投屏工具
- **PyQt5** — 图形界面框架

## ⚠️ 注意事项

- 冻结、卸载系统应用、清除数据等功能请谨慎操作
- 「断开所有无线设备」会强制结束所有 `adb.exe` 进程，包括 USB 连接
- 请勿在未备份的情况下卸载系统关键应用
- 首次使用请确保手机已授权本电脑的 USB 调试
